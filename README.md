# Prashant Gautam — Portfolio

Static, GitHub Pages-compatible portfolio for Prashant Gautam, Civil Engineer.

## Deploy

1. Upload the contents of this folder to the repository used for the site.
2. Keep `CNAME` at the repository root.
3. Enable GitHub Pages from the repository settings.
4. The custom domain is `prashant-gautam.com.np`.

## Included

- Responsive static HTML/CSS/JS site
- Project case studies for irrigation, post-fire assessment, mountain transportation and tourism infrastructure
- Post-fire project photo and field-video gallery
- Separate professional, transportation GRA, and post-fire/structural GRA CVs
- Light/dark theme and responsive navigation
- Accessible image viewer with keyboard and touch navigation
- `404.html`, `robots.txt`, `sitemap.xml`, canonical metadata and social sharing metadata

The portfolio language is intentionally written in first person and presents the site as Prashant Gautam's own professional work and application portfolio.
